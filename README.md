# SabzLearn - Educational Platform (SPA)

A Single Page Application (SPA) built as a full-stack educational platform with real backend integration.

## Key Features
- ✔ **User Authentication** (Signup/Login)
- ✔ **Course Purchasing** (with/without discount codes)
- ✔ **Pagination & Sorting for courses**
- ✔ **Commenting System**
- ✔ **User Dashboard**
- ✔ **Admin Panel** (CRUD for courses, articles & users)

**Tech Stack**
🔹 Frontend: React.js (SPA)
🔹 Backend: Node.js / Express (or your backend tech)
🔹 Database: MongoDB / SQL (or your DB)

- **Developed as a practice project with real-world functionalities.**
